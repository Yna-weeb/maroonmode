# MaroonMode — Next.js fashion website

Three routes: `/` (Home), `/collections` (search and filter), and `/product/1` (dynamic product details).

## Run the project

1. Install Node.js if you haven't already.
2. Open this `maroonmode` folder in VS Code.
3. In Terminal, run `npm install`.
4. Run `npm run dev`.
5. Visit http://localhost:3000

No database is required. Add to Bag is a demo interaction, not a real checkout/cart. Product prices are sample prices, and fashion photos load from Unsplash when the computer has internet access.
